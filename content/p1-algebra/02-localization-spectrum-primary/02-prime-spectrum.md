## The prime spectrum

### Statement

**Definition P1.2.13 (prime spectrum).** The *prime spectrum* $\operatorname{Spec} A$ is the set of prime ideals of $A$. For a subset $E \subseteq A$ let $V(E) = \{\mathfrak{p} : E \subseteq \mathfrak{p}\}$, and for $f \in A$ let $D(f) = \operatorname{Spec} A \setminus V(f)$. For a subset $Y \subseteq \operatorname{Spec} A$ let $I(Y) = \bigcap_{\mathfrak{p} \in Y} \mathfrak{p}$.

Lean: Mathlib `PrimeSpectrum`, `PrimeSpectrum.zeroLocus`, `PrimeSpectrum.basicOpen` and `PrimeSpectrum.vanishingIdeal` (definitions).

**Example P1.2.14.** $\operatorname{Spec} \mathbb{Z} = \{(0)\} \cup \{(p) : p \text{ prime}\}$. For an algebraically closed field $k$, $\operatorname{Spec} k[x] = \{(0)\} \cup \{(x - a) : a \in k\}$: the points of the line, and one more point $(0)$.

**Example P1.2.15.** For a field $K$, $\operatorname{Spec} K$ is one point. $\operatorname{Spec} 0 = \emptyset$. $\operatorname{Spec} k[x]/(x^2)$ is one point, the same as $\operatorname{Spec} k$, although the rings differ.

**Proposition P1.2.16 (Zariski topology).** The sets $V(E)$ are the closed sets of a topology on $\operatorname{Spec} A$, the *Zariski topology*. In detail: $V(E) = V(I) = V(\sqrt{I})$ for $I$ the ideal generated by $E$; $V(0) = \operatorname{Spec} A$ and $V(1) = \emptyset$; $V(\bigcup E_\lambda) = \bigcap V(E_\lambda)$; and $V(I \cap J) = V(IJ) = V(I) \cup V(J)$. Also $V(I) \subseteq V(J)$ if and only if $\sqrt{J} \subseteq \sqrt{I}$, and $I(V(I)) = \sqrt{I}$.

Lean: Mathlib `PrimeSpectrum.zeroLocus_span`, `PrimeSpectrum.zeroLocus_inf`, `PrimeSpectrum.zeroLocus_mul`, `PrimeSpectrum.zeroLocus_subset_zeroLocus_iff` and `PrimeSpectrum.vanishingIdeal_zeroLocus_eq_radical` (proved in Mathlib).

*Proof.* A prime contains $E$ if and only if it contains $I$, and if and only if it contains $\sqrt{I}$, because a prime that contains $a^n$ contains $a$. The next two facts are clear. For the last of the list, $IJ \subseteq I \cap J \subseteq I, J$ gives $V(I) \cup V(J) \subseteq V(I \cap J) \subseteq V(IJ)$. If $\mathfrak{p} \supseteq IJ$ and $\mathfrak{p} \not\supseteq I$, pick $a \in I \setminus \mathfrak{p}$. For every $b \in J$, $ab \in \mathfrak{p}$, so $b \in \mathfrak{p}$. So $\mathfrak{p} \in V(J)$. By the theorem on the nilradical in Section 1.1, applied to $A/I$, $\sqrt{I}$ is the intersection of the primes that contain $I$. This is $I(V(I)) = \sqrt{I}$, and it gives the inclusion criterion: if $V(I) \subseteq V(J)$, then $\sqrt{J} = I(V(J)) \subseteq I(V(I)) = \sqrt{I}$. $\square$

**Proposition P1.2.17 (basic open sets).** The sets $D(f)$ form a basis of the topology, and $D(f) \cap D(g) = D(fg)$. $D(f) = \emptyset$ if and only if $f$ is nilpotent, and $D(f) = \operatorname{Spec} A$ if and only if $f$ is a unit. The space $\operatorname{Spec} A$ is quasi-compact, and so is each $D(f)$.

Lean: Mathlib `PrimeSpectrum.isTopologicalBasis_basic_opens`, `PrimeSpectrum.basicOpen_mul`, `PrimeSpectrum.basicOpen_eq_bot_iff`, `PrimeSpectrum.compactSpace` and `PrimeSpectrum.isCompact_basicOpen` (proved in Mathlib).

*Proof.* An open set is $\operatorname{Spec} A \setminus V(E) = \bigcup_{f \in E} D(f)$, so the $D(f)$ form a basis. A prime misses $fg$ if and only if it misses $f$ and $g$. $D(f) = \emptyset$ means $f$ lies in every prime, which means $f$ is nilpotent. $D(f)$ is everything when $f$ lies in no prime, and that means $f$ is a unit, by Krull's theorem. For quasi-compactness it is enough to treat a cover of $D(f)$ by basic open sets $D(g_\lambda)$. The inclusion $D(f) \subseteq \bigcup D(g_\lambda)$ means $V(\{g_\lambda\}) \subseteq V(f)$, that is, $f \in \sqrt{(g_\lambda)_\lambda}$. So $f^n = \sum_{i=1}^r a_i g_{\lambda_i}$ for some $n$ and finitely many indices, and then $D(f) \subseteq D(g_{\lambda_1}) \cup \dots \cup D(g_{\lambda_r})$. The case $f = 1$ is $\operatorname{Spec} A$. $\square$

**Proposition P1.2.18 (closures and generic points).** For $Y \subseteq \operatorname{Spec} A$, the closure of $Y$ is $V(I(Y))$. In particular the closure of the point $\mathfrak{p}$ is $V(\mathfrak{p})$, a point $\mathfrak{p}$ is closed if and only if $\mathfrak{p}$ is maximal, and $\mathfrak{q}$ lies in the closure of $\mathfrak{p}$ if and only if $\mathfrak{p} \subseteq \mathfrak{q}$. A closed subset $V(I)$ is irreducible if and only if $\sqrt{I}$ is prime. So $\mathfrak{p} \mapsto V(\mathfrak{p})$ is a bijection from $\operatorname{Spec} A$ onto the set of irreducible closed subsets, and $\mathfrak{p}$ is the unique *generic point* of $V(\mathfrak{p})$: the unique point whose closure is $V(\mathfrak{p})$.

Lean: Mathlib `PrimeSpectrum.zeroLocus_vanishingIdeal_eq_closure`, `PrimeSpectrum.closure_singleton`, `PrimeSpectrum.isClosed_singleton_iff_isMaximal`, `PrimeSpectrum.le_iff_specializes` and `PrimeSpectrum.isIrreducible_zeroLocus_iff` (proved in Mathlib).

*Proof.* $V(I(Y))$ is closed and contains $Y$. If $V(E) \supseteq Y$ then $E \subseteq \mathfrak{p}$ for all $\mathfrak{p} \in Y$, so $E \subseteq I(Y)$ and $V(E) \supseteq V(I(Y))$. For $Y = \{\mathfrak{p}\}$ this gives $V(\mathfrak{p})$, which is $\{\mathfrak{p}\}$ exactly when no prime is strictly larger than $\mathfrak{p}$, that is, when $\mathfrak{p}$ is maximal (every proper ideal lies in a maximal ideal). Let $\mathfrak{p} = \sqrt{I}$ be prime and $V(I) = V(J_1) \cup V(J_2) = V(J_1 J_2)$ with radical ideals $J_i$. Then $\mathfrak{p} \in V(J_1J_2)$, so $\mathfrak{p} \in V(J_1)$, say, and $V(J_1) \supseteq V(\mathfrak{p}) = V(I)$. So $V(I)$ is irreducible. Conversely, if $V(I)$ is irreducible, $\mathfrak{p} = \sqrt{I} \neq A$ because $V(I) \neq \emptyset$, and $ab \in \mathfrak{p}$ gives $V(I) = V(I + (a)) \cup V(I + (b))$. By irreducibility, $V(I) = V(I + (a))$, say, so $a \in \sqrt{I}$. Uniqueness of the generic point: if $V(\mathfrak{p}) = V(\mathfrak{p}')$, then $\mathfrak{p} = I(V(\mathfrak{p})) = \mathfrak{p}'$. $\square$

**Proposition P1.2.19 (functoriality).** A ring homomorphism $\varphi: A \to B$ induces a continuous map $\varphi^*: \operatorname{Spec} B \to \operatorname{Spec} A$, $\mathfrak{q} \mapsto \varphi^{-1}(\mathfrak{q})$, with $(\varphi^*)^{-1}(D(f)) = D(\varphi(f))$. If $\varphi: A \to A/I$ is the quotient map, $\varphi^*$ is a homeomorphism onto the closed set $V(I)$. If $\varphi: A \to S^{-1}A$, $\varphi^*$ is a homeomorphism onto the set of primes that miss $S$; for $S = \{f^n\}$ this is the open set $D(f)$. For $\mathfrak{p} \in \operatorname{Spec} A$, the fibre $(\varphi^*)^{-1}(\mathfrak{p})$ is in bijection with $\operatorname{Spec}(B \otimes_A \kappa(\mathfrak{p}))$.

Lean: Mathlib `PrimeSpectrum.comap`, `PrimeSpectrum.isClosedEmbedding_comap_of_surjective`, `PrimeSpectrum.localization_comap_range` and `PrimeSpectrum.localization_away_isOpenEmbedding` (proved in Mathlib).

*Proof.* The preimage of a prime is prime, and $\varphi^{-1}(\mathfrak{q}) \ni f$ if and only if $\varphi(f) \in \mathfrak{q}$, which gives the formula for $D(f)$ and continuity. For $A/I$, the primes of $A/I$ are the $\mathfrak{p}/I$ with $\mathfrak{p} \supseteq I$, and $V(J/I)$ corresponds to $V(J)$, so the bijection onto $V(I)$ is a homeomorphism. For $S^{-1}A$ the bijection is the theorem on primes in Section 2.1; it maps $V(S^{-1}J)$ onto $V(J)$ intersected with the image, since $S^{-1}J \subseteq S^{-1}\mathfrak{p}$ if and only if $J \subseteq \mathfrak{p}$ for $\mathfrak{p}$ that miss $S$. For the fibre, $B \otimes_A \kappa(\mathfrak{p}) \cong T^{-1}(B/\mathfrak{p}B)$, where $T$ is the image of $A \setminus \mathfrak{p}$, by the corollary of Section 1.3 and the isomorphism $S^{-1}A \otimes M \cong S^{-1}M$. Its primes are the primes $\mathfrak{q}$ of $B$ that contain $\mathfrak{p}B$ and miss the image of $A \setminus \mathfrak{p}$, that is, with $\varphi^{-1}(\mathfrak{q}) = \mathfrak{p}$. $\square$

**Proposition P1.2.20 (connectedness and idempotents).** $\operatorname{Spec} A$ is disconnected if and only if $A$ has an idempotent $e \neq 0, 1$, that is, if and only if $A \cong A_1 \times A_2$ with $A_1, A_2 \neq 0$.

Lean: Mathlib `PrimeSpectrum.isIdempotentElemEquivClopens` (an order isomorphism between idempotents and clopen sets, proved in Mathlib).

*Proof.* If $e$ is idempotent, $e(1 - e) = 0$, so $D(e) \cap D(1 - e) = D(0) = \emptyset$, and no prime contains both $e$ and $1 - e$, so $D(e) \cup D(1 - e) = \operatorname{Spec} A$. If $e \neq 0, 1$, then $e$ and $1 - e$ are not nilpotent (an idempotent nilpotent is $0$), so both sets are nonempty. Conversely let $\operatorname{Spec} A = V(I) \sqcup V(J)$ with both parts nonempty. Then $V(I + J) = \emptyset$ gives $I + J = A$, and $V(IJ) = \operatorname{Spec} A$ gives $IJ \subseteq \operatorname{nil}(A)$. Write $1 = a + b$ with $a \in I$, $b \in J$, and choose $n$ with $(ab)^n = 0$. Since $V(a^n) \cap V(b^n) = V(a) \cap V(b) \subseteq V(I) \cap V(J) = \emptyset$, the ideal $(a^n, b^n)$ is $A$, so $1 = a^n u + b^n v$. Put $e = a^n u$. Then $e(1 - e) = a^n b^n uv = 0$, so $e$ is idempotent. As $e \in I$, $V(I) \subseteq V(e)$, and as $1 - e \in J$, $V(J) \subseteq V(1 - e)$. So $V(e) \neq \emptyset$ and $V(1 - e) \neq \emptyset$, and $e \neq 0, 1$. The ring decomposition is $A \cong A/(1 - e) \times A/(e)$, by the Chinese remainder theorem. $\square$

### Proof in words

$\operatorname{Spec} A$ is a space in which the ring acts as functions: the value of $f$ at $\mathfrak{p}$ is its image in $\kappa(\mathfrak{p})$, and $V(f)$ is where it vanishes. The topology is coarse. Points need not be closed, and the closure of a point $\mathfrak{p}$ is the subvariety $V(\mathfrak{p})$, with $\mathfrak{p}$ as its generic point. Quasi-compactness is the algebraic fact that $1 = \sum a_i f_i$ is always a finite sum.

For an affine variety $X$ over an algebraically closed field $k$ with $A = k[X]$, the closed points of $\operatorname{Spec} A$ are the maximal ideals, which are the points of $X$ by the Nullstellensatz of P0 Ch. 3. The topology on the closed points is the Zariski topology of $X$. The other points are the generic points of the irreducible closed subvarieties of positive dimension. Every nonempty closed subset of $\operatorname{Spec} A$ contains a closed point, by Krull's theorem, and Chapter 4 shows that the closed points are dense in every closed subset. So the extra points add no new closed or open sets, and $X$ and $\operatorname{Spec} A$ have the same lattice of open sets. The extra points pay their way: the local ring at the generic point of a divisor carries the order of vanishing, and the fibre of a morphism over a generic point is the generic fibre, a variety over the function field of the base. The MMP over a base $Z$ in Volume 1 often reduces to the generic fibre.

### Examples

**Example P1.2.21 (the affine plane).** Let $k$ be algebraically closed and $A = k[x, y]$. The points of $\operatorname{Spec} A$ are: the closed points $(x - a, y - b)$; for each irreducible polynomial $f$, the generic point $(f)$ of the curve $f = 0$; and the generic point $(0)$ of the plane. The closure of $(f)$ is the curve with its own generic point, and $(0)$ is dense. Exercise 5 below proves that these are all the primes.

**Example P1.2.22 (the real line).** $\operatorname{Spec} \mathbb{R}[x]$ has the closed points $(x - a)$ with $a \in \mathbb{R}$, the closed points $(x^2 + bx + c)$ with $b^2 < 4c$, and $(0)$. A point of the second kind is a pair of complex conjugate points, with residue field $\mathbb{C}$. The map $\operatorname{Spec} \mathbb{C}[x] \to \operatorname{Spec} \mathbb{R}[x]$ is onto, two to one over the points of the second kind.

**Example P1.2.23 (an arithmetic surface).** $\operatorname{Spec} \mathbb{Z}[x]$ maps to $\operatorname{Spec} \mathbb{Z}$. The fibre over $(p)$ is $\operatorname{Spec} \mathbb{F}_p[x]$, a line over $\mathbb{F}_p$. The fibre over $(0)$ is $\operatorname{Spec} \mathbb{Q}[x]$. The closed points are the maximal ideals $(p, f)$ with $f$ irreducible mod $p$. The prime $(x)$ is the generic point of a horizontal curve that meets every fibre, and $(p)$ is the generic point of the fibre over $p$.

**Example P1.2.24 (two components).** Let $A = k[x, y]/(xy)$. Then $\operatorname{Spec} A = V(x) \cup V(y)$, two lines that meet at the origin. It is connected but not irreducible, and its generic points are $(x)$ and $(y)$. By contrast $\operatorname{Spec} k[x]/(x(x - 1)) = \operatorname{Spec}(k \times k)$ is two points, disconnected, with the idempotent $e = 1 - x$.

### Exercises

1. (A) Describe $\operatorname{Spec} \mathbb{Z}/60$ and $\operatorname{Spec} k[x]/(x^2(x - 1))$ as topological spaces.
2. (A) Show that $D(f) \subseteq D(g)$ if and only if $f \in \sqrt{(g)}$, and that $\operatorname{Spec}(A_1 \times A_2) = \operatorname{Spec} A_1 \sqcup \operatorname{Spec} A_2$.
3. (A) Show that $\operatorname{Spec} A$ is irreducible if and only if $\operatorname{nil}(A)$ is prime.
4. (B) Show that $\varphi^*: \operatorname{Spec} B \to \operatorname{Spec} A$ has dense image if and only if $\ker \varphi \subseteq \operatorname{nil}(A)$.
5. (B) Let $k$ be algebraically closed. Show that a nonzero prime of $k[x, y]$ that is not maximal is principal. (Hint: if $\mathfrak{p}$ contains two coprime irreducible $f, g$, show that $k[x, y]/(f, g)$ is finite dimensional, by eliminating $y$ with the resultant.) Deduce the list of points in the first example.
6. (B) Let $\varphi: k[x] \to k[x, y]$ be the inclusion. Describe the fibres of $\varphi^*$ over $(x - a)$ and over $(0)$. Show that the fibre over $(0)$ is $\operatorname{Spec} k(x)[y]$ and that its closed points correspond to the irreducible curves in the plane other than the vertical lines $x = a$.
7. (C) Show that if every prime of $A$ is maximal, then $\operatorname{Spec} A$ is Hausdorff. (Hint: for distinct maximal $\mathfrak{m}, \mathfrak{m}'$, reduce modulo the nilradical and use that $A_\mathfrak{m}/\operatorname{nil}$ is a field.)

### Notes and history

The maximal spectrum of a ring of continuous functions goes back to Gelfand and to Stone in the 1930s. Grothendieck used all prime ideals in EGA I (1960), and the generic points made birational geometry part of the same space as the points. The literature state of every result here is theorem. The section follows Atiyah-Macdonald, Chapter 1, where these facts appear among the exercises, and Eisenbud, Chapter 2. P3 adds the structure sheaf and makes $\operatorname{Spec} A$ an affine scheme.
